# 每日工作计划

一个用于 Obsidian 的每日工作计划和项目待办插件。插件会读取指定目录下的 Markdown 笔记，并按“项目 -> 支线任务”的层级展示今日、逾期、未来 7 天、全部未完成、已完成和无日期事项。

## 默认数据目录

```text
所有笔记/待办事项/每日事项
```

可以在插件设置里修改数据目录。

## 功能

- 左侧栏打开“每日工作计划”视图
- 命令面板打开视图或新增每日事项
- 读取 Markdown 任务行：`- [ ]` / `- [x]`
- 读取 frontmatter 字段：`项目`、`date`、`开始时间`、`结束时间`、`待办状态`、`优先级`
- 按项目聚合任务，展示项目完成度和支线任务列表
- 支持今日、逾期、未来 7 天、全部、已完成、无日期筛选
- 支持搜索、刷新、打开来源笔记
- 支持在插件视图内标记完成或恢复未完成
- 支持新增每日事项或项目支线任务，并自动写入目标目录

## 安装

1. 下载或复制本仓库的 `main.js`、`manifest.json`、`styles.css`
2. 放入 Obsidian 库：

```text
.obsidian/plugins/daily-work-plan/
```

3. 重启 Obsidian
4. 在“设置 -> 第三方插件”中启用“每日工作计划”

## 每日事项格式示例

```markdown
---
date: 2026-06-26
待办状态: 未完成
类别: 每日事项
tags:
  - 每日计划
开始时间: 2026-06-26T09:00:00
结束时间: 2026-06-26T18:00:00
优先级: 中
项目: 日常工作
备注:
---
- [ ] 整理今日工作计划
```

## 项目和支线任务

同一个 `项目` 字段下的事项会自动聚合到一个项目卡片里。一个笔记里也可以写多个支线任务：

```markdown
---
date: 2026-06-26
待办状态: 未完成
类别: 每日事项
tags:
  - 每日计划
开始时间: 2026-06-26T09:00:00
结束时间: 2026-06-30T18:00:00
优先级: 高
项目: 视频号运营
备注:
---
- [ ] 选题整理
- [ ] 脚本初稿
- [ ] 视频剪辑
- [ ] 发布复盘
```

插件也兼容旧数据：没有 `项目` 字段的笔记会暂时按来源笔记标题归为一个项目。
